# GroundBreaker brand assets

**Aegis (GroundBreaker) — powered by Athena Software Group, Inc.**

Chosen direction: **01 · Thread & Labyrinth**. Ariadne's thread leaves the labyrinth and ends at a block.
Codename: **Aegis**. Release name: **GroundBreaker**.

| File | Use |
|---|---|

| `groundbreaker-mark-light.svg` | Square mark on Parchment |

| `../app/web/static/brand/favicon.svg` | 64 px favicon (thread and box only) |

`img/` holds copies of the dark mark and lockup for use in docs.

Palette: Aegis Navy `#0E1A2B` · Navy 2 `#13233A` · Athena Gold `#C9A227` · Gold-on-light `#9A7B1A` · Parchment `#F4EFE3`.
Type: Space Grotesk for the wordmark ("Ground" 400 + "Breaker" 700); IBM Plex Mono for descriptors and hashes.
Rules: gold is reserved for the thread/flow element. One accent, no gradients. Every mark must survive in a single colour at 16 px.
Company name: always "Athena Software Group, Inc." in full on first use, then "Athena Software Group".
