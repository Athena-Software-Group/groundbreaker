What happens

  • Outlook: open the reply, File → Save As (.msg), or drag it to the desktop.
  • Aegis reads it like mail from the case mailbox: the tracking tag [Aegis {{ case.reference }} #…] in the subject finds the letter it answers.
  • An uploaded file is never trusted on its own: it waits on Mail to review until a case admin accepts it. Only then is it filed on the authority's timeline (the e-mail and its attachments as R3 evidence) and the reply clock stops.
  • Nothing in an imported e-mail changes a status or sends anything. A .msg is converted for reading; the original file is kept as evidence.
